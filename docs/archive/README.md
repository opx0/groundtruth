# Archive

These files are superseded. They are kept for history, not as guidance.

- `IDEA-v2-superseded.md` is the second revision of the product idea. It
  proposed a language model writing the report text, NASA FIRMS and OpenAQ as
  sources, and geolocation input. The current brief forbids all three. Its
  wording also breaks the claim rules in `docs/BRIEF.md` section C2.
- `DATA-TESTS-bangalore-flood.md` records a flood-prediction experiment on
  Bangalore streets, from when the product was international. Ground Truth is
  US-only and makes no flood prediction. The terrain finding in it is real and
  reproducible, it just belongs to a different product.

The current source of truth is `docs/BRIEF.md`.
